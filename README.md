# Loose Land

A 2D factory/automation game built with Python and Pygame.

## Requirements

- Python 3.10+
- `pygame-ce` (or `pygame`)

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Run

```bash
python main.py
```
